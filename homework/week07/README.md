#学生成绩数据分析

##这个项目干什么
读入 120 个学生的成绩，做数据质量检查，分析班级和性别的差异、
期中到期末的进步、偏科情况，并画图。
##怎么运行
1. 安装依赖：`pip install -r requirements.txt`
2. 运行主程序：`python week07_analysis.py`
3. 数据文件 `scores.csv` 要和脚本放在同一个文件夹里


##输出什么
- 终端打印各项统计结果
- 生成两张图
- 分析报告在 `week07_报告.md`
##数据说明
`scores.csv` 是 Python 生成的模拟数据（随机种子 42），
包含 120 个学生的学号、班级、物理、数学、性别、期中、期末、作业。
